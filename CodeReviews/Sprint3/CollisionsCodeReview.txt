Specific comments on code quality:

Collision System:
Quadtree implementation lacks rebalancing, which impacts collision efficiency.
Broad-phase collision checks are inefficient and need optimization.
Entity bounds updates occur too frequently, causing unnecessary processing overhead.
Missing a collision layer system to allow for efficient filtering.
Collision Commands:
Collision handling for movable blocks is overcomplicated; should be streamlined.
Some commands are tightly coupled to specific entities instead of being generic.
